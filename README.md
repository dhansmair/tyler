# 『Tyler』
Tiling window manager for MacOS, inspired by XMonad.  
Purely written by Claude Code.

## Features
- Stack-based tiling
- Mouse support: window resizing, drag-and-drop swapping
- Trackpad gesture support: use three-finger-swipe to move between workspaces
- Menu bar indicator
- Multiple layouts: tall, fullscreen, strip (niri-inspired)
- Customizable keybindings
