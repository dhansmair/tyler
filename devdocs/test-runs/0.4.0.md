# 0.4.0

- Date: 2026-11-08
- macOS: 26.7.2 on the Mac; 26.6.2 in the VM
- Build: the release branch (`docs/changelog-0.4.0`), 84fd9a8 for LIFE-START and LIFE-STOP, e2978b7 (with #125) for every other row; a development build, `Tyler.app` signed with a self-made identity on the Mac, a bare `tylerd` in the VM
- Displays: on the Mac, the built-in display and an external display above it; in the VM, one virtual display (1024x768 at first, 2548x1370 from LIFE-RESTART on, after the VM window was resized)
- Skipped contexts: displays side by side (the VM's two-display mode wasn't opened), three displays, unplugging and the lid
- Where: the rows marked "in the VM" ran in a tart VM (`devdocs/macos-vm.md`), driven through `tart exec` with `tyler` commands, AppleScript and posted keys, on throwaway TextEdit and terminal windows; the rows marked "on the Mac" on the Mac in daily use, on throwaway TextEdit windows on an empty workspace, those "by a person" with the developer moving the mouse. This run covers what changed since 0.3.0 (#118, #122, #125), not the whole catalogue: the last full run is `0.3.0.md`. TALL-ANIM is a timing row and was judged on the Mac only: the VM's virtual display reached about 30 frames a second
- Found by the run: a floated window switched away from during its float animation came back to its old slot (#125, fixed before these rows were finished); a restart from another install can move a window to the other display's workspace (#127, open, also seen before 0.4.0's last changes; not known whether 0.3.0 has it)
